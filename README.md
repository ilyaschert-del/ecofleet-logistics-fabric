# EcoFleet & Logistics Fabric

Cloud-based logistics analytics platform using Microsoft Fabric.

## Main Components

- Batch ingestion: Microsoft Fabric Data Factory
- Storage: OneLake / Lakehouse
- Data processing: Apache Spark / PySpark
- Streaming: Python IoT Simulator
- Real-time analytics: Eventstream, Eventhouse, KQL
- Machine Learning: Delay and fuel consumption prediction
- Visualization: Power BI
- Security: Microsoft Entra ID and governance

## Dataset

Logistics Operations Database (2022-2024)

Source:
https://www.kaggle.com/datasets/yogape/logistics-operations-database

The historical dataset contains 14 CSV files.
